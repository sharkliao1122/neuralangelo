重要先說

- 這表示這個 better output 對應的實際訓練超參數，本質上是 fast_safe 這一套設定被保存到目前這個輸出資料夾中。

一、chair_from_nerf2mesh_better 的所有參數與功用

[checkpoint]
checkpoint.save_epoch = 9999999999
- 作用: 以 epoch 為單位存檔的週期。設成極大值代表幾乎不靠 epoch 觸發存檔。

checkpoint.save_iter = 50000
- 作用: 每 50000 次 iteration 存一次 checkpoint。
- 實際效果: 會在 50k, 100k, 150k ... 500k 這些步數留下模型檔。

checkpoint.save_latest_iter = 9999999999
- 作用: 以 iteration 為單位更新 latest checkpoint 的週期。
- 實際效果: 設成極大值，代表不靠這個機制頻繁更新 latest。

checkpoint.save_period = 9999999999
- 作用: 通用週期型存檔參數。
- 實際效果: 設成極大值，等同幾乎停用這條存檔觸發路徑。

checkpoint.strict_resume = true
- 作用: Resume 時要求 checkpoint 內容和目前模型結構嚴格對齊。
- 影響: 可避免載入到不相容權重，但如果你改過模型結構，resume 會更容易直接報錯。

[cudnn]
cudnn.benchmark = true
- 作用: 讓 cuDNN 幫固定 shape 的運算挑較快的 kernel。
- 影響: 速度通常較好，尤其輸入尺寸固定時更有利。

cudnn.deterministic = false
- 作用: 不強制完全可重現的 deterministic kernel。
- 影響: 速度通常較佳，但每次跑可能存在極小數值差異。

[data]
data.name = dummy
- 作用: 資料集名稱欄位。這裡主要是框架層需要的佔位名稱。

data.num_images = null
- 作用: 若指定數量，通常表示只使用部分影像。
- 影響: 這裡是 null，表示不在這裡做人為截斷。

data.num_workers = 4
- 作用: DataLoader 開幾個 worker 載入資料。
- 影響: 數值越大通常資料讀取越平行，但也更吃 CPU / RAM。

data.preload = true

- 影響: 可減少訓練中反覆讀圖的 I/O 開銷，但會多吃記憶體。

trainer.loss_weight.curvature = 0.0005
- 作用: 曲率正則項權重。
- 影響: 控制幾何表面的平滑 / 正則化強度。

trainer.loss_weight.eikonal = 0.1
- 作用: Eikonal loss 權重。
- 影響: 對 SDF 很重要，用來約束梯度長度接近 1，幫助保持合法距離場。

trainer.loss_weight.render = 1.0
- 作用: 影像重建 loss 權重。
- 影響: 是主要的顏色 / 渲染擬合目標。

trainer.type = projects.neuralangelo.trainer
- 作用: 指定訓練器實作類別。

[validation and wandb]
validation_iter = 10000
- 作用: 每 10000 iteration 做一次 validation。
- 影響: 比較省時間，但比 official 更少檢查。

wandb_image_iter = 10000
- 作用: 每 10000 iteration 往 Weights & Biases 上傳一次影像。

wandb_scalar_iter = 100
- 作用: 每 100 iteration 往 Weights & Biases 上傳一次 scalar 指標。

==================================================
二、和 official 版相比，哪些參數被改過
==================================================

以下比較是用兩份實際輸出資料夾中的固化 config.yaml 直接比對得到的結果。

1. checkpoint.save_iter
- official: 20000
- better: 50000
- 差異意義: better 版存 checkpoint 的頻率更低。
- 實際影響:
  - 優點: 少一些存檔 I/O，訓練流程更乾淨。
  - 缺點: 中途中斷時，可回復的最近進度點比較疏。

2. trainer.amp_config.enabled
- official: false
- better: true
- 差異意義: better 版啟用了 AMP mixed precision。
- 實際影響:
  - 優點: 通常更快，也更省顯存。
  - 代價: 可能帶來些微數值差異，少數情況下也可能增加數值不穩風險。
- 這一項是 better 版和 official 版最重要的訓練差異。

3. validation_iter
- official: 5000
- better: 10000
- 差異意義: better 版做 validation 的頻率只有 official 的一半。
- 實際影響:
  - 優點: 少花時間在驗證上，整體訓練更快。
  - 缺點: 比較晚發現畫面退化、NaN、或收斂異常。

4. logdir
- official: logs/chair/chair_from_nerf2mesh_official
- better: logs\chair\chair_from_nerf2mesh_fast_safe
- 差異意義: 這主要是 run 名稱與路徑標記不同。
- 實際影響:
  - 它本身不是模型超參數，不直接改變訓練數學行為。
  - 但它清楚指出 better 這份 config 其實是 fast_safe 這組 run 的設定快照。

==================================================
三、總結
==================================================

就實際固化設定來看，chair_from_nerf2mesh_better 相較於 official，真正改動的核心只有三類:
- 啟用 AMP
- 降低 checkpoint 存檔頻率
- 降低 validation 頻率

其餘模型結構、資料路徑、解析度、batch size、learning rate、scheduler、loss 權重、hashgrid 設定、ray 採樣數等，在這兩份固化 config 中都是相同的。

如果你之後要追問「哪一項最可能讓訓練加快」，優先看這兩個:
- trainer.amp_config.enabled = true
- validation_iter 從 5000 拉到 10000

如果你之後要追問「哪一項最可能影響最終品質或穩定性」，優先看這兩個:
- trainer.amp_config.enabled = true
- checkpoint.save_iter 變大後，中途中斷時的可恢復粒度變粗
